# ⚡ Pokémon TCG — Simulador de Booster (11 Cartas)

Simulador interativo em HTML5, CSS3 e JavaScript puro para abertura de um pacote Booster de Pokémon TCG contendo 11 cartas especiais, pronto para hospedagem gratuita no **GitHub Pages**.

## 🚀 Como publicar no GitHub Pages (Passo a Passo)

1. Crie um novo repositório no [GitHub](https://github.com/new) (público).
2. Envie todos os arquivos desta pasta (`index.html`, pasta `assets/`, `.nojekyll`, etc.) para o repositório:
   - **Pelo navegador (sem precisar de Git instalado)**: Na página do seu repositório recém-criado, clique em **"uploading an existing file"**, arraste o arquivo `index.html` e a pasta `assets` para a área de upload e clique em **"Commit changes"**.
3. Ative o **GitHub Pages**:
   - No seu repositório, vá na aba **Settings** (Configurações) ➔ **Pages** (no menu lateral esquerdo).
   - Em **Build and deployment** > **Source**, selecione **Deploy from a branch** (ou **GitHub Actions**).
   - Se escolher **Deploy from a branch**, selecione a branch `main` (ou `master`), pasta `/ (root)` e clique em **Save**.
4. Aguarde cerca de 1 minuto e seu site estará no ar no link:
   `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`

## 💡 Personalização Opcional via Link (URL)
Caso queira personalizar o nome que aparece na 11ª carta diretamente pelo link enviado:
```text
https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/?para=NomeDaPessoa
```
